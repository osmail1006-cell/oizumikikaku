# Claude Codeに最初に貼り付ける指示

大泉企画のホームページとブログ運用を引き継いでください。
GitHub：https://github.com/osmail1006-cell/oizumikikaku
公開HP：https://oizumikikaku.pages.dev/

1. 既存のローカルクローンがなければ、このリポジトリを空の新規フォルダへcloneしてください。既存の作業を上書きしないでください。
2. 最新mainのCLAUDE.md、CLAUDE_HANDOFF.md、BLOG_WORKFLOW.md、prompts/weekly-blog.mdと実際のコードを読んでください。Node.jsのビルドを実行し、現在の記事数と公開状態を確認してください。
3. 既存のClaude側の定期タスクを確認し、同じサイトを更新するタスクがあればそれを更新してください。重複タスクは作らないでください。
4. Claude Codeのクラウド定期タスクを、毎週月曜日8:00・Asia/Tokyoで設定してください。対象リポジトリはosmail1006-cell/oizumikikaku、開始点は最新mainです。毎回prompts/weekly-blog.mdの内容を読み、そこに従って記事を1本作成し、通常のコミット・mainへのpush・Cloudflare本番の確認まで行う設定にしてください。個別記事が成功してもタスク自体は継続してください。
5. 定期タスクには作業ブランチを作るだけでなく、既存の許可範囲でmainまで公開する指示を含めてください。ブランチ保護や権限が妨げる場合は回避せず、具体的な所有者操作を示してください。
6. CLIでは /schedule、利用できなければ https://claude.ai/code/routines のクラウド定期タスク画面を使ってください。CLI内の /loop は長期の週次運用の代用にしないでください。
7. 追加のAPI課金・使用量の超過課金・有料契約を勝手に有効化しないでください。利用中プランで使える範囲を確認し、ログイン・GitHub連携・対象リポジトリの書き込み許可が必要なら、その操作だけを具体的に案内してください。パスワードやトークンを文章やGitに貼らせないでください。
8. 定期タスク作成後に「今すぐ実行」で1回試し、実際の記事が本番に公開されたことを確認してください。当週に記事があれば重複投稿せず公開確認だけ行ってください。
9. 「定期タスクの登録」「次回予定とタイムゾーン」「手動テスト」「本番公開」の各結果を分けて報告してください。できなかった部分を完了としないでください。

この依頼はブログの週次運用の引き継ぎです。既存HPの連絡先・フォーム・デザインは無関係に変更しないでください。
